01 · Genuine model output

No random percentages, simulated latency, or invented forensic artifacts. A result is shown only when the inference API returns it.

02 · Short-clip caution

Clips under four seconds require padding, which can materially change model scores. Longer, clear samples are preferable.

03 · Telephone caution

Genuine telephone speech has triggered false positives in testing. Do not use a score alone to accuse or verify a caller.
